## 2026-08-13 — 56 파일 삭제 (사용자 결정)

사용자 지시: *"실패에 대한 이력이 이미 해소된 내용이고 오래된 내용이면 판단후 삭제해도 됩니다."*

**삭제한 것**: 2026-04 ~ 2026-06 시점의 회고·감사·설계 문서 중
**리포 어디에서도 참조되지 않는** 56 파일 (약 622KB). 판정 절차:

1. `git grep -l -F <basename> -- . ':!docs/_archive'` 가 **0건**인 파일만 후보로 삼았다.
   살아있는 소비자(스크립트·테스트·활성 문서)가 하나라도 있으면 제외했다 — 실제로 20건이 이 축에서 걸렸다.
2. 후보 전건에 대해 *미해결 · 잔여 · 보류 · TODO* 를 스캔하고 상위 히트를 직접 읽었다.
3. 그중 **살아있는 일감 1건**(P4-Gate-2 = rubocop·golangci-lint 실바이너리 미실증)을 발견해
   `docs/backlog.md` **R87** 로 승격한 뒤에 삭제했다. 나머지는 사이클 60~91 시점의 프로세스
   메모였고, 그때 제안된 정책은 전부 `.claude/policies/active.md` 에 이미 반영돼 있다.
4. `docs/_archive/reports/INDEX.md` 의 대응 행 38개를 같은 커밋에서 제거했다
   (전단사 가드 `tests/unit/scripts/test_docs_ledger_shape.py` 가 양방향을 강제한다).

**남긴 것**: 2026-07 이후 회고·감사 · 살아있는 참조가 있는 시점 기록 ·
`rules-incident-log.md`(규칙 완화 시 먼저 읽어야 하는 사고 원장).

**복구 방법**: 삭제는 git 이력에 남는다.

```bash
git log --diff-filter=D --name-only -- 'docs/_archive/**'   # 무엇이 언제 지워졌나
git show <sha>^:docs/_archive/<파일>                          # 원문 복원
```

**왜 지웠나** — 총량 절감이 이유가 아니다(그 근거는 2026-08-11 계획서가 이미 기각했다).
읽히지 않는 곳에서 **열린 일감이 3.5개월 늙은 것**이 실제 손해였다. R87 이 그 증거다.
