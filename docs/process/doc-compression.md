# 흐름 — 문서를 줄이거나 옮길 때

> **언제 여는가**: 문서를 압축·삭제·이동하기 **직전**.
>
> 이 흐름이 생긴 이유: 2026-08-12~13 세션에 압축·이동을 3회 했고 **매번 다른 축이 깨졌다**.
> 셋 다 착수 전 3분이면 예측할 수 있었다.

---

## 1. 착수 전 3문 — 하나라도 "예" 면 그 축을 먼저 처리한다

### (a) 이 파일을 **픽스처로 쓰는 테스트**가 있는가

```bash
grep -rn "<파일경로>" tests/ scripts/ .claude/hooks/ .github/workflows/
```

실측: `cycle-history.md` 를 압축하자 *"실행 지시 어휘 + 인용 면제 마커를 함께 든 실물"* 을
쓰던 테스트의 **전제가 비었다**. 어휘가 아카이브로 옮겨갔기 때문이다.

### (b) **앵커·링크 소비자**가 있는가

```bash
py -3 scripts/check_toc_anchors.py        # 활성 `## 목차` 문서 TOC 앵커
grep -rn "<파일명>#" docs/ .claude/        # 앵커 참조
```

실측: TOC 를 재생성하며 slug 을 **자체 구현**했더니 `+` 처리가 어긋나 앵커 2건이 끊겼다.
→ **가드의 `github_slug` 를 직접 import 한다.** 사본을 만들면 또 갈라진다.

### (c) 지워지는 내용에 **열린 일감**이 있는가

```bash
grep -nE "잔여|미해결|미이행|TODO|GROK-[0-9]" <파일>
```

실측: `backlog.md` 의 ✅ 40행 중 **21행이 미해결 잔여**를 담고 있었고,
그중 **17행은 어느 열린 행에도 귀속되지 않았다**. 맹목 삭제였으면 통째로 사라졌다.

**정규식 추출을 검증 없이 믿지 마라** — 위 21건 중 4건은 표기가 달라 정규식이 놓쳤다.
원문에서 읽고 손으로 채웠다.

---

## 2. 끝난 이력은 옮기지 않고 지운다

끝난 작업의 서사·계획·회고·설계는 **그림자 트리를 만들지 않는다.** 열린 상태는
GitHub Issues 에 남긴다.

지운 뒤에는 그 경로를 가리키던 가드·글롭·색인·헤더를 **같은 작업에서** 끊는다.
빈 분모를 채점하는 글롭을 남기지 않는다.

## 3. 경로를 바꾸면 전수 grep 후에

```bash
git ls-files | xargs grep -l "<옛 경로>" 2>/dev/null    # 전 추적 파일
```

살아있는 소비자(스크립트·훅·테스트·CI·색인)만 갱신한다. 실측(2026-08-13 재편)에서 깨진 것:

| 깨진 것 | 형태 |
|---|---|
| 스캐너 범위 | `_plan_docs()` 가 옛 경로를 봐 **9→3 으로 좁아짐** |
| 등급 패턴 | 구 `integrations`(low_risk) 가 `runbooks` 로 합쳐지며 **런북 전체를 강등시킬 뻔** |
| 치환 잔재 | 구 `^\.claude/plans/` → 새 경로 치환에서 이스케이프 깨짐 |

## 4. 검증 — 이 순서로

```bash
py -3 scripts/pre_push_gate.py            # 게이트 전건
py -3 -m pytest tests/unit -q             # 전체 스위트 (예외 없음)
py -3 scripts/check_red_budget.py         # 🔴 분모가 사라지지 않았는지
```

**`git stash` 를 쓰지 마라.** 이동(`git mv`)이 unstage 돼 `git ls-files` 가 옛 경로를
반환하고, 그 목록으로 parametrize 하는 테스트가 무더기로 red 가 된다(실측 29건).
비교가 필요하면 **격리 worktree** 를 쓴다:

```bash
git worktree add --detach <임시경로> origin/main
```

---

## 5. 수치가 변했으면 원인을 밝힌다

테스트 수가 줄었을 때 *"삭제"* 인지 *"parametrize 대상 변화"* 인지 구별한다.
격리 worktree 로 main 과 대조하면 확정된다. 구별하지 않고 STATE 에 적으면
다음 세션이 **테스트가 사라졌다**고 읽는다.

## 이 흐름이 막지 못하는 것

- **내용이 옳은지** 는 보지 않는다 — 옮긴 글이 원문과 같은 뜻인지는 사람이 읽어야 한다.
- **아카이브가 나중에 읽히는지** 도 모른다. 도달성은 [`traps C2`](../../.claude/traps.md) 축이다.
