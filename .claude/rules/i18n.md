# 다국어 / i18n 규칙

> 여기 남은 것은 규칙 · 왜 한 줄 · 가드 파일명이다.

## 발신 경로 "0건" 은 수동 grep 으로 선언하지 않는다

- **사용자 발신 한글 부재는 자동 테스트로만 단언한다.**
  수동 `grep '[가-힣]'` 은 Jinja 블록·서버 렌더 토스트를 놓치고, 디렉토리 한정 grep 은 다른 디렉토리 호출을 놓친다.
  🔴 **검증 단위는 디렉토리가 아니라 발신 API 호출** — 호출을 역추적한다.
  가드: `tests/unit/notifier/test_no_hardcoded_korean_in_send_modules.py`.
- **동기/비동기 발신 경로 비대칭 금지** — GitHub 댓글·Telegram·Discord·Slack·Email·Issue 는 같은 방식으로 i18n. 한쪽만 하면 언어가 갈린다.
- 🔴 **render-parity 가드 동반** — 키 존재 테스트는 템플릿 오타 키가 raw 로 노출되는 것을 못 잡는다. 신규 키는 실제 렌더 결과를 단언한다.
  패턴: `tests/unit/templates/test_detail_i18n_render.py`.
- **upstream 데이터 필드도 i18n 대상** — `summary=ai_review.summary` 처럼 데이터 값을 보간하면 그 값의 언어를 같이 정한다.
- **내부 로그는 i18n 대상이 아니다** — `logger.warning(...)` 은 운영자용.

## 언어 결정 (코드가 하는 일)

- **웹 locale (`src/middleware/locale.py::_detect_locale`, 75-99행)** — Cookie `preferred_language` → Accept-Language q-weight → `settings.default_locale` → `settings.locale_fallback`.
  `User.preferred_language` 는 이 미들웨어에 **없다** (SessionMiddleware 가 outer 라 `scope["session"]` 미설정 — 모듈 docstring 12-18행). 로그인 후 preferred_language 는 Cookie 로 동기화한다. ASGI 직접 (`BaseHTTPMiddleware` 아님).
- **알림 언어 (`src/notifier/_language.py::resolve_notification_language`)** — `User.preferred_language` → `RepoConfig.notification_language` → `settings.default_locale` (env `DEFAULT_LOCALE`, 기본 `'en'`).
- **AI 리뷰 언어 (`src/worker/pipeline.py::_resolve_review_language`)** — `Repository.user_id` → `User.preferred_language` → `settings.default_locale`.
- **hook** — 세션 locale 없음. `_resolve_hook_locale` (`src/api/hook.py:38-56`) 가 `Repository.full_name` → `user_id` → `User.preferred_language`, 없으면 `settings.default_locale`.
- **`notification_language`** 는 `field_validator` 로 `SUPPORTED_LOCALES` 검증 (`src/api/repos.py` — None/빈값은 fallback 허용).

## 번역 파일 / 템플릿

- **단일 출처 = `src/i18n/translations/{en,ko,ja}.json`** (Python dict + LRU). namespace 변경 시 `docs/architecture.md` 동기화.
- **Jinja2** = `{{ 'key.path' | i18n_args(locale | default('ko'), arg=value) }}`. `default('ko')` 필수 — LocaleMiddleware 를 안 거치는 영역이 있다.
- **`settings.*` 키 추가/제거** — 번역 3파일 + `settings.html` + `tests/unit/test_i18n_settings.py` 의 `_KEYS`. 누락 시 parametrize 가 다른 영역 테스트를 깨뜨린다.
- **`<label class="toggle-switch">`** 는 accessible name 이 없다 → `aria-label` (Sonar S6853). 페어 = [`ui.md`](ui.md) `InputWithoutLabelCheck`.

## 관측

- Anthropic prompt cache 는 언어별 가이드가 system text 에 들어가 hash 가 갈린다 (의도).
- `src/services/operations_service.py::operations_kpi` 가 `language_distribution` · `i18n_fallback` 카드를 낸다. 메모리 카운터는 사용처 ≥ 3 이면 헬퍼 (정책 16).
