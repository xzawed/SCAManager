> 🔴 **사고 재현·측정 로그는 [`docs/_archive/rules-incident-log.md#i18n`](../../docs/_archive/rules-incident-log.md#i18n) 로 옮겼다 — 규칙을 완화·삭제하려면 아카이브를 먼저 읽을 것** (2026-08-12 밀도 압축).
> 이 영역은 *"0건 실측"* 선언이 **3회 연속 뒤집힌** 이력이 있다 — 서사가 짧아진 것이 규칙이 약해졌다는 뜻이 아니다.
> 역링크·앵커 도달성만 잰다(서사 보존은 기계 집행 아님 — R81 옵션 (b), 2026-08-15): `tests/unit/scripts/test_rules_archive_backlink.py`.

## "다 했다" 가 반복해서 거짓이었던 영역

- **발신 경로 "0건" 은 수동 grep 으로 선언 금지 — 자동 테스트로만.**
  *왜*: 사이클 152·153·154 가 각각 *"완결"* 을 선언했고 **매번 다음 회고가 누락을 찾았다**.
  실패 형태 = (a) `grep '[가-힣]'` 이 Jinja 블록 내부·서버 렌더 토스트를 놓침
  (b) 디렉토리 한정 grep 이 다른 디렉토리의 발신 호출을 놓침.
  🔴 **검증 단위는 디렉토리가 아니라 "발신 API 호출" 이다** — 호출을 역추적할 것.
  가드: `tests/unit/notifier/test_no_hardcoded_korean_in_send_modules.py`(사이클 155 봉인).
- **동기/비동기 발신 경로 비대칭 금지** — 사용자 발신(GitHub 댓글·Telegram·Discord·Slack·Email·Issue)은
  **모든 경로가 동일하게** i18n 되어야 한다. 한쪽만 하면 언어가 갈린다.
- 🔴 **render-parity 가드 동반 의무** — 키 존재 테스트만으로는 템플릿의 **오타 키**가 raw 키로 노출되는 것을 못 잡는다.
  신규 키 추가 시 실제 렌더 결과를 단언하는 가드를 함께 만든다.
  패턴 정본: `tests/unit/templates/test_detail_i18n_render.py`.
- **upstream 데이터 필드도 i18n 대상** — i18n 키에 `summary=ai_review.summary` 처럼 **데이터 값을 보간**하면
  그 값 자체가 다른 언어일 수 있다. 출처 필드의 언어를 함께 결정할 것.
- **내부 로그는 i18n 대상이 아니다** — `logger.warning(...)` 은 운영자용이다. 사용자 발신만 대상.

## 언어 결정

- **locale 감지 5단계** — `src/middleware/locale.py` 의 `LocaleMiddleware`(ASGI 직접, BaseHTTPMiddleware 우회):
  Cookie(`preferred_language`) > Accept-Language q-weight > `User.preferred_language` > 기본값.
- **알림 언어 3-layer fallback** — `User.preferred_language` → `RepoConfig.notification_language`
  → `settings.default_locale` → `"en"`.
- **AI 리뷰 언어 2-layer** — `Repository.user_id` → `User.preferred_language` → `settings.default_locale` → `"en"`.
- **hook 경로는 세션 locale 이 없다** — `_resolve_hook_locale(db, repo_name)` 으로
  `Repository.full_name` → `user_id` → `User.preferred_language` 해소.
- **`notification_language` 는 `field_validator` 로 `SUPPORTED_LOCALES` 검증 의무**(None/빈값은 fallback 의도로 허용).

## 번역 파일 / 템플릿

- **단일 출처 = `src/i18n/translations/{en,ko,ja}.json`** (Babel 미사용 — Python dict + LRU).
  namespace 구성 변경 시 `docs/architecture.md` 동기화 의무.
- **Jinja2 호출 패턴** = `{{ 'key.path' | i18n_args(locale | default('ko'), arg=value) }}`.
  `default('ko')` **필수** — LocaleMiddleware 를 통과하지 않는 영역이 있다.
- **`settings.*` 키 추가/제거 시 3곳 동시 갱신** — 번역 3파일 + `settings.html` 참조 + `test_i18n_settings._KEYS`.
  누락 시 parametrize 연쇄로 **다른 영역** 테스트가 깨진다.
- **`<label class="toggle-switch">` 는 accessible name 이 없다**(라벨 텍스트가 형제 요소에 있음)
  → `aria-label` 부여 의무(SonarCloud S6853). 페어 = [`ui.md`](ui.md) `InputWithoutLabelCheck`.

## 관측

- **Anthropic prompt cache 는 언어별로 자동 분리된다** — system text 에 언어별 가이드가 들어가 hash 가 달라진다(의도).
- **운영 KPI** — `src/services/operations_service.py` 의 `operations_kpi` 가 `language_distribution` 과
  `i18n_fallback` 카드를 낸다. 메모리 카운터 패턴은 사용처 ≥3 도달 시 헬퍼 추출(정책 16).
- **smoke 회귀** — `tests/integration/test_i18n_smoke.py`(3 언어 × `/login` Cookie + HTML `lang` 일치 + default fallback).
